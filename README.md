# Oh My fnOS Theme · Beta

一个只在用户手动确认的 fnOS 地址上运行的 Chromium 浏览器扩展。Beta 聚焦登录页外观、标签标题与 favicon。它不修改 NAS 文件，不拦截表单，不读取密码、Cookie 或网络请求，也不连接外部服务。

## 权限设计

- 安装后没有任何 NAS 站点权限，也不会自动扫描浏览器地址。
- 扩展仅声明 `http` / `https` 的可选站点权限。用户在插件页面录入地址并确认后，浏览器才会为该地址显示授权请求。
- 浏览器扩展 API 需要 `scripting` 执行已授权站点的内容脚本，需要 `storage` 保存用户确认的地址和外观设置。
- 内容脚本先校验实际 origin，再确认页面中存在 fnOS / 飞牛标记；登录样式只在检测到密码字段时启用。
- 移除地址会注销对应的动态脚本并撤销该站点授权。

## 安装与使用

1. 在 Chrome 或 Edge 打开扩展管理页并启用开发者模式。
2. 选择“加载已解压的扩展程序”，选中仓库目录。
3. 打开扩展设置，输入完整 NAS 地址，例如 `http://192.168.1.20:5666` 或 `https://nas.example.com`。
4. 查看显示的地址后点击“确认地址并授权”，再由浏览器原生弹窗确认该站点权限。
5. 刷新 fnOS 登录页。插件在之后访问已确认地址时自动运行。

地址必须是 http 或 https 的站点根地址，可以包含端口，不能包含路径、查询参数、用户名或密码。权限匹配会明确包含端口（默认使用 HTTP 80 / HTTPS 443），并覆盖该端口下的页面路径；页面本身仍会再经过 fnOS 特征检测。

## Beta 当前范围

- 登录页深色渐层背景、玻璃卡片、表单控件与按钮样式。
- 已确认地址的自动应用总开关。
- 可自定义标签标题、登录页问候语、辅助文案、强调色及 favicon。
- 登录表单结构和 fnOS 认证流程保持原样。
- 仅支持 Chrome / Edge Manifest V3；因暂时没有实际 fnOS 设备页面，本项目的登录表单识别需要在用户设备上校准。
- [登录页概念预览](preview.html) 是静态视觉稿，不包含 fnOS 登录能力。

## 浏览器兼容

插件使用 Chromium Manifest V3 的 `scripting.registerContentScripts`、`permissions.request` 和 `storage.local` API。它只在用户添加的地址获得站点访问权。
