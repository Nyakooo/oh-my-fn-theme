# Oh My fnOS Theme · Beta

一个只在用户手动确认的 fnOS 地址上运行的 Chromium 浏览器扩展。Beta 聚焦登录页、桌面 Dock、标签标题与 favicon。它不修改 NAS 文件，不拦截表单，不读取密码、Cookie 或网络请求，也不连接外部服务。

## 权限设计

- 安装后没有任何 NAS 站点权限，也不会自动扫描浏览器地址。
- 扩展仅声明 `http` / `https` 的可选站点权限。用户在插件页面录入地址并确认后，浏览器才会为该地址显示授权请求。
- 浏览器扩展 API 需要 `scripting` 执行已授权站点的内容脚本，需要 `storage` 保存用户确认的地址和外观设置。
- 内容脚本只在用户确认的 origin 运行；登录样式只在检测到密码字段时启用，不依赖页面品牌文字或标题。
- 桌面 Dock 样式只在识别到 fnOS 原生 Dock DOM 结构时启用；内容脚本只标记原生节点，不替换节点、不拦截点击事件。
- 扩展启动、升级或已确认地址列表变化时，会按仍有效的站点授权自动恢复并更新动态脚本注册。
- 移除地址会注销对应的动态脚本并撤销该站点授权。

## 安装与使用

1. 在 Chrome 或 Edge 打开扩展管理页并启用开发者模式。
2. 选择“加载已解压的扩展程序”，选中仓库目录。
3. 打开扩展设置，输入完整 NAS 地址，例如 `http://192.168.1.20:5666` 或 `https://nas.example.com`。
4. 查看显示的地址后点击“确认地址并授权”，再由浏览器原生弹窗确认该站点权限。
5. 刷新 fnOS 登录页。插件在之后访问已确认地址时自动运行。

地址必须是 http 或 https 的站点根地址，可以包含端口，不能包含路径、查询参数、用户名或密码。权限匹配会明确包含端口（默认使用 HTTP 80 / HTTPS 443），并覆盖该端口下的页面路径。子域名和跳转后的不同主机名需要分别确认。

## Beta 当前范围

- 提供“极简”和“月夜居所”两种主题，默认使用极简风格；月夜居所同时应用紧凑 Dock，极简保留 fnOS 原生 Dock。
- “月夜居所”主题包含月夜餐桌插画、饭团/月亮/盆栽/筷子互动；两种主题都包裹现有 fnOS 登录表单并保留原认证提交流程。关闭主题或离开登录页时恢复原面板位置。
- 已确认地址的自动应用总开关。
- 可自定义浏览器标签标题和 favicon；各主题使用自己的配色和布局。
- 月夜居所的 Dock 方案参考 [fnOS_UI_Mods](https://github.com/aurysian-yan/fnOS_UI_Mods) 的原生 Dock DOM，采用窄型悬浮轨道、紧凑纵向图标、浅色选中项和克制的悬停反馈。
- 仅支持 Chrome / Edge Manifest V3；fnOS 页面组件可能随系统版本变化，登录表单与 Dock 结构仍需在目标设备上校准。
- [登录页主题预览](preview.html) 使用同一份内容脚本和样式模拟注入效果，可在右上角切换主题；表单不会连接 NAS 或发送输入内容。
- [fnOS 内部桌面设计预览](internal-preview.html) 展示与“月夜居所”登录主题相配的桌面首页和 Dock 栏，使用本地交互样例数据；预览加载真实内容脚本，按 fnOS 原生 Dock DOM 结构验证主题注入。
- [fnOS 深色桌面 Dock 预览](desktop-preview.html) 按实际桌面截图重现左侧系统栏、桌面应用和右侧状态卡片，用于验证居中悬浮 Dock 的尺寸、分组与选中状态。

## 浏览器兼容

插件使用 Chromium Manifest V3 的 `scripting.registerContentScripts`、`permissions.request` 和 `storage.local` API。它只在用户添加的地址获得站点访问权。
